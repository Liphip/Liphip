## Projects
### Expense Tracker
[Expense Tracker](https://expenses.liphip.de) is a web app that helps users manage expenses for social events. The app is open source and available on [GitHub](https://github.com/Liphip/expense_tracker). It is built using HTML, CSS, and JavaScript, with a focus on user-friendly design and functionality. The app is responsive and works well on both desktop and mobile devices.

**Key Features:**
- Add, delete, and clear expenses
- Download expenses as CSV
- Save/load data from a file
- Add guests and tags
- Overview section for detailed insights
